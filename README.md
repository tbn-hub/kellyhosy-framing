# KELLYHOSY Framing

Static framing lookbook for collectors. There is no build step: Netlify publishes this folder as it is.

- `index.html` is the page. Frame styles, specs and captions live in the `STYLES` list in the script at the bottom.
- `img/` holds the 4:5 photos (1200 x 1500). `share.jpg` is the WhatsApp and social link preview.

Link straight to a style with `#teak-float`, `#teak-double-mat`, `#red-oak-sandwich`, `#beech-sandwich` or `#glazing`.
